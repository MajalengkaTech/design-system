## Yang berubah dibanding situs asli

- **Layanan dulu, berita kemudian.** Kotak pencarian di bagian atas mencari layanan, termasuk kata yang biasa dipakai warga seperti "pkl" atau "ijazah hilang".
- **Ikon menggantikan emoji.** Emoji ikut dibacakan pembaca layar dan tampilannya berbeda di tiap perangkat.
- **Yang tidak membantu warga dibuang**: berita nasional dari portal lain dan statistik pengunjung.
- **Detail layanan siap dipakai**: daftar "yang perlu dibawa", langkah bernomor, FAQ, dan kotak ringkasan biaya, tempat, dan jam.

## Yang dipakai dari design system

| Lapisan | Dipakai untuk |
|---|---|
| `@majalengka/css` | Header, menu, drawer ponsel, kartu, tombol, input, badge, breadcrumb, accordion, alert, footer, pita keterangan |
| `@majalengka/tokens/preset` | Utilitas UnoCSS dari token, mis. `bg-mjl-bg-brand-subtle` dan `text-mjl-text-strong` |
| `@majalengka/js` | Menu ponsel dengan `<dialog commandfor>` dan tombol "Selengkapnya" |

## Hasil pemeriksaan

- **axe-core WCAG 2.2 AA**: 0 pelanggaran di 6 halaman, mode terang dan gelap.
- **Tanpa JavaScript**: pencarian dan halaman detail tetap berfungsi pada versi server (`bun run dev:disdik`).
- **Ponsel 390px**: tidak ada scroll horizontal.

---

## Menjalankan sendiri

```bash
git clone https://github.com/MajalengkaTech/design-system.git
cd design-system
bun install
bun run dev:disdik   # http://localhost:3001
```

Untuk proyek sendiri, salin folder `templates/disdik`, lalu ganti isi `app/data/layanan.ts` dan `app/data/situs.ts` dengan data instansi Anda.
