# Definition of Done (DoD)

Sebelum komponen atau halaman layanan baru dinyatakan selesai (*done*) dan dapat digabungkan ke cabang utama (*main*), kriteria berikut wajib terpenuhi:

1. **Aksesibilitas Terverifikasi**
   - Lolos audit otomatis `axe-core` atau Lighthouse Aksesibilitas dengan skor minimal **95**.
   - Telah diuji dengan navigasi keyboard murni (tanpa mouse).
   - Target sentuh terbukti minimal 44×44px di tampilan layar HP (360px).
2. **Kesesuaian Desain Token**
   - Tidak ada nilai *hardcoded* (misal `#0014A8` ditulis langsung di inline-style atau kelas ad-hoc). Seluruh warna, spasi, radius, dan bayangan wajib mengambil dari token CSS `--mjl-*`.
3. **Kompatibilitas Lintas Perangkat**
   - Berfungsi mulus pada resolusi 360px (ponsel murah Android), 768px (tablet), dan 1280px (desktop kantor).
   - Tidak menyebabkan *horizontal scrolling* yang merusak tata letak pada HP layar kecil.
4. **Dokumentasi & Contoh Kode**
   - Tersedia contoh pemakaian untuk jalur CSS murni dan komponen Vue 3.
   - Microcopy dan pesan error telah direviu sesuai panduan bahasa Anti-Kaku.
