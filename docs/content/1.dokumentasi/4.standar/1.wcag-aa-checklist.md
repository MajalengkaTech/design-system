# Daftar Periksa WCAG 2.1 Level AA

Semua website dinas dan aplikasi layanan publik di lingkungan Pemerintah Kabupaten Majalengka wajib lolos uji mandiri berikut sebelum dipublikasikan ke domain `.go.id` atau `majalengka.tech`.

## 1. Persepsi (Perceivable)

- [ ] **Teks Alternatif (SC 1.1.1)**: Seluruh gambar memiliki atribut `alt`. Gambar hiasan menggunakan `alt=""`.
- [ ] **Rasio Kontras Teks (SC 1.4.3)**: Teks normal minimal kontras **4.5:1** terhadap latar belakang. Teks besar (≥18px bold atau ≥24px regular) minimal **3:1**.
- [ ] **Kontras Antarmuka Non-Teks (SC 1.4.11)**: Garis batas input form, ikon navigasi, dan focus ring minimal kontras **3:1**.
- [ ] **Perubahan Ukuran Teks (SC 1.4.4)**: Teks dapat diperbesar hingga 200% tanpa ada konten yang terpotong atau tumpang tindih.

## 2. Pengoperasian (Operable)

- [ ] **Navigasi Keyboard Penuh (SC 2.1.1)**: Semua tombol, tautan, input, dan menu modal dapat diakses dan diaktifkan hanya dengan tombol `Tab`, `Enter`, `Spasi`, dan `Esc`.
- [ ] **Tidak Ada Jebakan Fokus (SC 2.1.2)**: Fokus keyboard tidak boleh terkunci mati di dalam elemen tertentu.
- [ ] **Tautan Lompat Konten / SkipLink (SC 2.4.1)**: Tersedia tombol `SkipLink` di baris pertama dokumen HTML.
- [ ] **Indikator Fokus Jelas (SC 2.4.7)**: Garis fokus (focus ring) berukuran minimal 3px tebal dan tidak boleh dihilangkan dengan `outline: none`.
- [ ] **Target Sentuh Minimum 44×44px (SC 2.5.5)**: Tombol dan ikon aksi memiliki bidang klik minimal 44 piksel.

## 3. Pemahaman (Understandable)

- [ ] **Bahasa Dokumen (SC 3.1.1)**: Tag `<html lang="id">` terdefinisi secara eksplisit.
- [ ] **Label Input Jelas (SC 3.3.2)**: Setiap kolom isian memiliki label teks yang terlihat permanen.
- [ ] **Identifikasi Kesalahan (SC 3.3.1)**: Pesan kesalahan form menjelaskan secara spesifik letak kesalahan dan bagaimana cara memperbaikinya.

## 4. Ketahanan (Robust)

- [ ] **Nama, Peran, Nilai ARIA (SC 4.1.2)**: Komponen kustom (modal, stepper, tabs) menggunakan peran ARIA standar yang dikenali pembaca layar (*screen reader*).
