# Prinsip 2: Framework-Agnostic

Di pemerintahan daerah, ekosistem teknologi sangat beragam: ada dinas yang mempekerjakan vendor modern berbasis React/Vue/Nuxt, namun ada pula puluhan aplikasi kecamatan dan puskesmas warisan (*legacy*) yang dibangun di atas PHP Native, CodeIgniter 3, atau WordPress tanpa proses build Node.js.

## Solusi Tanpa Hambatan Adopsi

Jika sistem desain mewajibkan `npm install` dan bundler canggih, maka 70% aplikasi instansi daerah otomatis menolak memakainya.

Oleh karena itu:
- **Paket CSS Mandiri (`@majalengka/css`) adalah jalur utama, bukan pelengkap.**
- Cukup satu tag `<link rel="stylesheet" href="...">`, seluruh warna resmi, tipografi, dan gaya tombol langsung aktif.
- Token desain berbasis CSS Custom Properties baku W3C DTCG yang dapat dikonsumsi oleh teknologi apa pun.
