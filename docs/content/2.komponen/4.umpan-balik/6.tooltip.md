# Tooltip

Tooltip menyajikan penjelasan ringkas tentang fungsi suatu tombol atau ikon tanpa memakan ruang visual permanen.

---

## Pratinjau Komponen

<div class="mjl-demo-box">
  <div style="display: flex; gap: 24px; align-items: center;">
    <button class="mjl-btn mjl-btn--secondary mjl-btn--md" data-mjl-tooltip="Unduh salinan berkas PDF">
      Unduh PDF
    </button>

    <span style="font-size: 14px; text-decoration: underline dotted; cursor: help;" data-mjl-tooltip="Nomor Induk Kependudukan 16 digit">
      Apa itu NIK?
    </span>
  </div>
</div>

---

## Penggunaan CSS Murni

Cukup sematkan atribut `data-mjl-tooltip`:

```html
<button class="mjl-btn mjl-btn--secondary mjl-btn--md" data-mjl-tooltip="Cetak tanda terima bukti lapor">
  Cetak Bukti
</button>
```
