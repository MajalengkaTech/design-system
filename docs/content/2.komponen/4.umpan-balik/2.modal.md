# Modal (Kotak Dialog Konfirmasi)

Modal (`.mjl-modal`) menghentikan sementara interaksi halaman di belakangnya untuk meminta keputusan warga — seperti konfirmasi penghapusan draf permohonan atau pembatalan antrean.

---

## 1. Pratinjau Tampilan Modal

::component-demo{title="Pratinjau Kotak Dialog"}
<div class="mjl-modal border border-slate-200 shadow-md">
  <div class="mjl-modal__header">
    <h3 class="mjl-modal__title">Batalkan Pengajuan Ini?</h3>
    <button type="button" class="mjl-modal__close" aria-label="Tutup Dialog">✕</button>
  </div>
  <p class="text-sm text-slate-600 leading-relaxed">
    Seluruh isian data formulir KTP Elektronik dan foto dokumen yang sudah Anda unggah akan dihapus secara permanen dari server. Tindakan ini tidak dapat dibatalkan.
  </p>
  <div class="mjl-modal__footer">
    <button type="button" class="mjl-btn mjl-btn--outline">Tetap Lanjutkan</button>
    <button type="button" class="mjl-btn mjl-btn--danger">Ya, Batalkan</button>
  </div>
</div>

#code
```html
<div class="mjl-modal-backdrop">
  <div class="mjl-modal" role="dialog" aria-modal="true" aria-labelledby="modal-title">
    <div class="mjl-modal__header">
      <h3 id="modal-title" class="mjl-modal__title">Batalkan Pengajuan?</h3>
      <button type="button" class="mjl-modal__close" aria-label="Tutup">✕</button>
    </div>
    <div class="mjl-modal__body">
      <p>Data yang telah Anda isi akan terhapus.</p>
    </div>
    <div class="mjl-modal__footer">
      <button type="button" class="mjl-btn mjl-btn--outline">Batal</button>
      <button type="button" class="mjl-btn mjl-btn--danger">Ya, Hapus</button>
    </div>
  </div>
</div>
```
