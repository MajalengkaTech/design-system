# Modal (Kotak Dialog Konfirmasi)

Modal (`.mjl-modal`) menghentikan sementara interaksi dengan halaman di belakangnya untuk meminta keputusan warga, misalnya sebelum menghapus draf permohonan atau membatalkan antrean.

---

## 1. Coba langsung

::component-demo{title="Modal konfirmasi"}
<button type="button" class="mjl-btn mjl-btn--danger" commandfor="demo-modal" command="show-modal">Batalkan pengajuan</button>

<dialog id="demo-modal" class="mjl-modal" closedby="any" aria-labelledby="demo-modal-title">
  <div class="mjl-modal__header">
    <div id="demo-modal-title" class="mjl-modal__title">Batalkan pengajuan ini?</div>
    <button type="button" class="mjl-modal__close" commandfor="demo-modal" command="close" aria-label="Tutup">✕</button>
  </div>
  <p>Isian formulir KTP Elektronik dan foto dokumen yang sudah Anda unggah akan dihapus permanen. Tindakan ini tidak bisa dibatalkan.</p>
  <div class="mjl-modal__footer">
    <button type="button" class="mjl-btn mjl-btn--secondary" commandfor="demo-modal" command="close">Tetap lanjutkan</button>
    <button type="button" class="mjl-btn mjl-btn--danger" commandfor="demo-modal" command="close">Ya, batalkan</button>
  </div>
</dialog>

#code
```html
<button type="button" class="mjl-btn mjl-btn--danger"
        commandfor="batal" command="show-modal">
  Batalkan pengajuan
</button>

<dialog id="batal" class="mjl-modal" closedby="any" aria-labelledby="batal-judul">
  <div class="mjl-modal__header">
    <h3 id="batal-judul" class="mjl-modal__title">Batalkan pengajuan ini?</h3>
    <button type="button" class="mjl-modal__close"
            commandfor="batal" command="close" aria-label="Tutup">✕</button>
  </div>
  <p>Data yang sudah Anda isi akan terhapus.</p>
  <div class="mjl-modal__footer">
    <button type="button" class="mjl-btn mjl-btn--secondary"
            commandfor="batal" command="close">Tetap lanjutkan</button>
    <button type="button" class="mjl-btn mjl-btn--danger"
            commandfor="batal" command="close">Ya, batalkan</button>
  </div>
</dialog>
```
::

---

## 2. Cara kerjanya

Modal memakai elemen `<dialog>` bawaan browser, jadi hal-hal yang biasanya harus ditulis sendiri sudah beres:

- Fokus pindah ke dalam modal saat dibuka, dan kembali ke tombol pembuka saat ditutup.
- Tombol `Tab` tidak bisa keluar ke halaman di belakang modal.
- `Esc` menutup modal.
- Halaman di belakangnya tidak ikut ter-scroll.

Tombol pembuka dan penutup cukup memakai atribut `commandfor` (id dialog) dan `command`:

| `command` | Hasil |
|---|---|
| `show-modal` | Membuka dialog sebagai modal |
| `close` | Menutup dialog |

Atribut `closedby="any"` membuat klik di luar kotak modal ikut menutup. Hilangkan atribut ini untuk dialog yang wajib dijawab.

::note
Browser modern sudah memahami `commandfor` dan `closedby` tanpa JavaScript. Untuk browser lama, muat `@majalengka/js` supaya perilakunya sama:

```html
<script src="https://cdn.jsdelivr.net/npm/@majalengka/js/dist/majalengka.iife.js" defer></script>
```
::

---

## 3. Membuka lewat JavaScript

Kalau modal perlu dibuka dari kode (misalnya setelah validasi server), panggil method bawaan `<dialog>`:

```js
document.getElementById('batal').showModal()
document.getElementById('batal').close()
```

---

## 4. Kaidah penulisan

- Judul berupa pertanyaan yang jelas: "Batalkan pengajuan ini?", bukan "Konfirmasi".
- Label tombol menyebut tindakannya: "Ya, batalkan", bukan "Ya" atau "OK".
- Tombol berbahaya memakai varian `danger`, dan tombol amannya varian `secondary`.
- Selalu isi `aria-labelledby` dengan id judul modal.
