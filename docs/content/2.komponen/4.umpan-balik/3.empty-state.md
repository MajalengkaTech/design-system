# EmptyState (Kondisi Data Kosong)

Komponen EmptyState (`.mjl-empty-state`) mencegah warga mengira sistem sedang rusak saat daftar permohonan atau pencarian bernilai nol. Komponen ini memberikan penjelasan jelas dan tombol tindakan pertama.

---
