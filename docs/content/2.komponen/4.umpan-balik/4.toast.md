# Toast

Toast memberi konfirmasi cepat, misalnya "Draf tersimpan", tanpa menghentikan apa yang sedang dikerjakan warga.

---

## 1. Coba langsung

::component-demo{title="Toast"}
:toast-demo

#code
```js
import { toast } from '@majalengka/js'

toast({
  title: 'Permohonan terkirim',
  description: 'Nomor registrasi dikirim lewat SMS.',
  variant: 'success',
})
```
::

Di situs tanpa build step, pakai versi `<script>`:

```html
<script src="https://cdn.jsdelivr.net/npm/@majalengka/js/dist/majalengka.iife.js" defer></script>
<script>
  Mjl.toast({ title: 'Draf tersimpan', variant: 'info' })
</script>
```

---

## 2. Opsi

| Opsi | Tipe | Default | Keterangan |
|---|---|---|---|
| `title` | `string` | — | Wajib. Kalimat singkat hasil tindakan. |
| `description` | `string` | — | Detail tambahan. |
| `variant` | `'success' \| 'info' \| 'warning' \| 'danger'` | — | Warna garis kiri. |
| `duration` | `number` (ms) | `6000`, atau `0` untuk `danger` | `0` berarti tetap tampil sampai ditutup. |
| `closeLabel` | `string` | `"Tutup notifikasi"` | Label tombol tutup untuk pembaca layar. |

`toast()` mengembalikan `{ close() }` untuk menutupnya dari kode.

---

## 3. Aksesibilitas bawaan

- Wadah toast adalah live region (`aria-live="polite"`), jadi pembaca layar membacakan toast baru tanpa memindahkan fokus.
- Toast `danger` memakai `role="alert"` supaya langsung dibacakan, dan **tidak hilang sendiri**: pesan kesalahan tidak boleh lenyap sebelum sempat dibaca.
- Timer berhenti selama kursor atau fokus keyboard ada di toast (WCAG 2.2.1).
- Tombol tutup 32×32px, di atas batas minimal WCAG 2.5.8.

::warning
Jangan pakai toast untuk informasi yang wajib dibaca atau butuh tindakan, seperti kesalahan isian formulir. Tampilkan pesan itu di dekat kolomnya dengan [FormField](/komponen/formulir/form-field).
::
