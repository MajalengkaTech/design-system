# Progress

Menampilkan kemajuan kuantitatif dari suatu proses (misal: kelengkapan berkas 75%) untuk membangkitkan efek psikologis **Goal-Gradient**.

---

## Pratinjau Komponen

  <div style="display: flex; flex-direction: column; gap: 16px; max-width: 480px;">
    <div>
      <div style="display: flex; justify-content: space-between; font-size: 13px; margin-bottom: 6px; font-weight: 500;">
        <span>Kelengkapan Berkas Persyaratan</span>
        <span class="mjl-tabular-nums">75%</span>
      </div>
      <div class="mjl-progress">
        <div class="mjl-progress__bar" style="width: 75%;"></div>
      </div>
    </div>

    <div>
      <div style="font-size: 13px; margin-bottom: 6px; font-weight: 500;">
        <span>Memverifikasi Tanda Tangan Elektronik...</span>
      </div>
      <div class="mjl-progress mjl-progress--indeterminate">
        <div class="mjl-progress__bar"></div>
      </div>
    </div>
  </div>
</div>

## Penggunaan CSS Murni

```html
<!-- Determinate Progress (75%) -->
<div class="mjl-progress" role="progressbar" aria-valuenow="75" aria-valuemin="0" aria-valuemax="100">
  <div class="mjl-progress__bar" style="width: 75%;"></div>
</div>

<!-- Indeterminate Loading Bar -->
<div class="mjl-progress mjl-progress--indeterminate">
  <div class="mjl-progress__bar"></div>
</div>
```
