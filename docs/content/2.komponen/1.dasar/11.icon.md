## Tabel Ukuran

| Ukuran | Dimensi | Peruntukan |
| :--- | :--- | :--- |
| `xs` | 14×14 px | Teks keterangan mikro, badge kecil |
| `sm` | 16×16 px | Tombol kecil (`sm`), kolom input |
| `md` | 20×20 px | Standar tombol (`md`), navigasi |
| `lg` | 24×24 px | Aksi utama, header kartu |
| `xl` | 32×32 px | Empty state, dialog informasi |
