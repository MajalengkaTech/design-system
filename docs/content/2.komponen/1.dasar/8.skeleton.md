# Skeleton

Skeleton mempertahankan tata letak halaman saat data sedang diambil dari server, mencegah pergeseran tata letak kumulatif (CLS) dan mematuhi **Ambang Batas Doherty (< 400ms)**.

## Aksesibilitas (Reduced Motion)

Bila pengguna mengaktifkan preferensi *Reduced Motion* pada sistem operasinya, animasi gelombang berkilau (shimmer) akan otomatis dinonaktifkan dan digantikan dengan warna abu-abu statis yang tenang.

```html
<!-- Kartu Pemuatan Skeleton -->
<div class="mjl-card">
  <div class="mjl-skeleton mjl-skeleton--circle" style="width: 40px; height: 40px;"></div>
  <div class="mjl-skeleton mjl-skeleton--title" style="margin-top: 12px;"></div>
  <div class="mjl-skeleton mjl-skeleton--text"></div>
  <div class="mjl-skeleton mjl-skeleton--text" style="width: 60%;"></div>
</div>
```
