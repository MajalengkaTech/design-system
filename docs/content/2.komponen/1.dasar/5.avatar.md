## Penggunaan CSS Murni

```html
<!-- Avatar Inisial Bulat -->
<span class="mjl-avatar mjl-avatar--md mjl-avatar--circle">
  <span class="mjl-avatar__fallback">MJ</span>
</span>

<!-- Avatar Foto -->
<span class="mjl-avatar mjl-avatar--lg mjl-avatar--circle">
  <img class="mjl-avatar__image" src="/foto-warga.jpg" alt="Foto Warga">
</span>

<!-- Grup Tumpuk -->
<div class="mjl-avatar-group">
  <span class="mjl-avatar mjl-avatar--md mjl-avatar--circle">A</span>
  <span class="mjl-avatar mjl-avatar--md mjl-avatar--circle">B</span>
</div>
```
