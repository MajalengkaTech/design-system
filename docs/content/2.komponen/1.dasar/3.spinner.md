# Spinner (Indikator Pemuatan)

Spinner (`.mjl-spinner`) mengindikasikan bahwa sistem sedang melakukan pemrosesan di latar belakang — seperti query data kependudukan atau upload berkas berukuran besar.

---

## 1. Pratinjau Ukuran & Warna

<div class="flex items-center gap-6 p-4">
  <div class="flex items-center gap-2">
    <span class="mjl-spinner mjl-spinner--sm"></span>
    <span class="text-xs text-slate-500">Kecil (14px)</span>
  </div>
  <div class="flex items-center gap-2">
    <span class="mjl-spinner"></span>
    <span class="text-sm text-slate-600 font-medium">Standar (20px)</span>
  </div>
  <div class="flex items-center gap-2">
    <span class="mjl-spinner mjl-spinner--lg"></span>
    <span class="text-sm text-slate-700 font-bold">Besar (32px)</span>
  </div>
</div>

#code
```html
<!-- Ukuran Kecil: Cocok di dalam tombol sm atau badge -->
<span class="mjl-spinner mjl-spinner--sm"></span>

<!-- Ukuran Standar: Default tombol atau formulir -->
<span class="mjl-spinner"></span>

<!-- Ukuran Besar: Pemuatan satu layar penuh atau tabel -->
<span class="mjl-spinner mjl-spinner--lg"></span>
```
::

## 2. Pemuatan di Dalam Tombol

Ketika warga menekan tombol **"Kirim Berkas"**, gantilah ikon atau tambahkan spinner putih di samping teks:

::component-demo{title="Spinner di Dalam Tombol"}
<div class="flex gap-4">
  <button type="button" class="mjl-btn mjl-btn--primary" aria-busy="true" disabled>
    <span class="mjl-spinner mjl-spinner--sm mjl-spinner--white mr-2"></span>
    Menyimpan Data...
  </button>
  <button type="button" class="mjl-btn mjl-btn--secondary" aria-busy="true" disabled>
    <span class="mjl-spinner mjl-spinner--sm mr-2"></span>
    Mengunduh PDF...
  </button>
</div>

#code
```html
<button type="button" class="mjl-btn mjl-btn--primary" aria-busy="true" disabled>
  <span class="mjl-spinner mjl-spinner--sm mjl-spinner--white"></span>
  Menyimpan Data...
</button>
```
::

---

## 3. Kaidah Aksesibilitas

1. **Atribut `aria-busy="true"`**: Pasang pada kontainer atau tombol yang sedang memuat agar pembaca layar menginformasikan pengguna bahwa konten sedang diperbarui.
2. **Teks Pendamping Tersembunyi**: Selalu sertakan teks pembaca layar seperti `<span class="sr-only">Sedang memuat data...</span>` jika spinner ditampilkan tanpa label teks visual.
