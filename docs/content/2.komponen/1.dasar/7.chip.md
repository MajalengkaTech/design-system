---
title: Chip (Notifikasi Overlay)
description: Titik atau angka penanda notifikasi yang diletakkan di sudut elemen interaktif.
---

Chip diletakkan di atas avatar atau tombol untuk menunjukkan status aktif atau jumlah berkas yang menunggu tindakan.

---

## Pratinjau Komponen

<div class="mjl-demo-box">
  <div style="display: flex; align-items: center; gap: 24px;">
    <!-- Avatar dengan Dot Online -->
    <div class="mjl-chip-wrapper">
      <span class="mjl-avatar mjl-avatar--md mjl-avatar--circle">PT</span>
      <span class="mjl-chip mjl-chip--dot mjl-chip--success"></span>
    </div>

    <!-- Tombol dengan Badge Counter -->
    <div class="mjl-chip-wrapper">
      <button class="mjl-btn mjl-btn--secondary mjl-btn--md">
        Surat Masuk
      </button>
      <span class="mjl-chip">5</span>
    </div>
  </div>
</div>

---

## Penggunaan CSS Murni

```html
<!-- Dot Status -->
<div class="mjl-chip-wrapper">
  <span class="mjl-avatar mjl-avatar--md mjl-avatar--circle">PT</span>
  <span class="mjl-chip mjl-chip--dot mjl-chip--success"></span>
</div>

<!-- Counter Badge -->
<div class="mjl-chip-wrapper">
  <button class="mjl-btn mjl-btn--secondary mjl-btn--md">Pesan</button>
  <span class="mjl-chip">12</span>
</div>
```

---

## Penggunaan Vue 3 (`@majalengka/vue`)

```vue
<!-- import { MjlChip } from '@majalengka/vue' -->
<MjlChip :count="12" label="12 pesan belum dibaca">
  <MjlButton variant="secondary">Pesan</MjlButton>
</MjlChip>

<MjlChip dot variant="success" label="Sedang daring">
  <MjlAvatar name="Putri Tanjung" />
</MjlChip>
```

Angka pada chip disembunyikan dari pembaca layar (`aria-hidden`); prop `label` wajib diisi sebagai gantinya. Angka di atas `max` (default 99) tampil sebagai `99+`.
