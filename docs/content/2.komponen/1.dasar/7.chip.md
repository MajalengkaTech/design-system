# Chip

Chip diletakkan di atas avatar atau tombol untuk menunjukkan status aktif atau jumlah berkas yang menunggu tindakan.

---

## Pratinjau Komponen

<div class="mjl-demo-box">
  <div style="display: flex; align-items: center; gap: 24px;">
    <!-- Avatar dengan Dot Online -->
    <div class="mjl-chip-wrapper">
      <span class="mjl-avatar mjl-avatar--md mjl-avatar--circle">PT</span>
      <span class="mjl-chip mjl-chip--dot mjl-chip--success"></span>
    </div>

    <!-- Tombol dengan Badge Counter -->
    <div class="mjl-chip-wrapper">
      <button class="mjl-btn mjl-btn--secondary mjl-btn--md">
        Surat Masuk
      </button>
      <span class="mjl-chip">5</span>
    </div>
  </div>
</div>

---

## Penggunaan CSS Murni

```html
<!-- Dot Status -->
<div class="mjl-chip-wrapper">
  <span class="mjl-avatar mjl-avatar--md mjl-avatar--circle">PT</span>
  <span class="mjl-chip mjl-chip--dot mjl-chip--success"></span>
</div>

<!-- Counter Badge -->
<div class="mjl-chip-wrapper">
  <button class="mjl-btn mjl-btn--secondary mjl-btn--md">Pesan</button>
  <span class="mjl-chip">12</span>
</div>
```
