# Badge (Lencana Status)

Badge (`.mjl-badge`) berfungsi memberikan penanda status cepat kepada warga dan operator sistem mengenai kondisi suatu data atau permohonan — seperti status *Menunggu Verifikasi*, *Disetujui*, atau *Ditolak*.

---

```html
<!-- Status Disetujui / Selesai -->
<span class="mjl-badge mjl-badge--success">Disetujui</span>

<!-- Status Dalam Antrean / Verifikasi -->

<span class="mjl-badge mjl-badge--danger">Berkas Ditolak</span>
```

## 2. Rasio Kontras Aksesibilitas (WCAG 2.1 AA)

Semua kombinasi warna teks dan latar belakang badge telah diuji agar terbaca jelas oleh penderita gangguan penglihatan warna:

| Status | Warna Latar Belakang | Warna Teks | Rasio Kontras | Status WCAG AA |
| :--- | :--- | :--- | :--- | :--- |
| **Success** | `#E6F6ED` (Hijau Muda) | `#0F7B4A` (Hijau Tua) | **4.9:1** | ✅ Lolos (Min 4.5:1) |
| **Warning** | `#FEF3E6` (Kuning Jingga) | `#A65A00` (Cokelat Tua) | **5.4:1** | ✅ Lolos (Min 4.5:1) |
| **Danger** | `#FDF2F2` (Merah Muda) | `#B3261E` (Merah Tua) | **5.8:1** | ✅ Lolos (Min 4.5:1) |
| **Info** | `#EBF5FB` (Biru Langit) | `#0B6FA4` (Biru Tua) | **5.1:1** | ✅ Lolos (Min 4.5:1) |
| **Neutral** | `#EEF0F4` (Abu-abu) | `#363D4D` (Abu Gelap) | **8.2:1** | ✅ Lolos (Min 4.5:1) |

## 3. Integrasi Vue 3 (`@majalengka/vue`)

```vue
<script setup lang="ts">
import { MjlBadge } from '@majalengka/vue';
</script>

<template>
  <div class="flex items-center gap-2">
    <MjlBadge status="success" dot>Permohonan Selesai</MjlBadge>
    <MjlBadge status="warning">Perlu Perbaikan KTP</MjlBadge>
    <MjlBadge status="info">Diproses Disdukcapil</MjlBadge>
  </div>
</template>
```

### Properti Komponen (Props API)

| Properti | Tipe | Nilai Bawaan | Deskripsi |
| :--- | :--- | :--- | :--- |
| `status` | `'success' \| 'warning' \| 'danger' \| 'info' \| 'neutral'` | `'neutral'` | Nada warna semantik badge |
| `dot` | `boolean` | `false` | Menampilkan indikator titik bulat di sebelah kiri teks |
| `pill` | `boolean` | `false` | Menggunakan sudut membulat penuh (*fully rounded*) |
