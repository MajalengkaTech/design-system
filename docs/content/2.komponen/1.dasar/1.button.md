# Button (Tombol)

Tombol (`.mjl-btn`) adalah elemen interaktif utama yang digunakan warga dan petugas untuk mengeksekusi tindakan — seperti mengirim permohonan, mengunduh bukti tanda terima, atau membuka modal konfirmasi.

Semua tombol di Majalengka Design System memenuhi standar **WCAG 2.1 Level AA** dengan ukuran sentuh minimum **44×44px** pada perangkat seluler.

#code
```html
<!-- Tombol Utama (Aksi Primer Tunggal) -->
<button type="button" class="mjl-btn mjl-btn--primary">Tombol Utama</button>

<!-- Tombol Sekunder -->
<button type="button" class="mjl-btn mjl-btn--secondary">Sekunder</button>

<!-- Tombol Garis Luar (Outline) -->
<button type="button" class="mjl-btn mjl-btn--outline">Garis Luar</button>

<!-- Tombol Tanpa Garis (Ghost) -->
<button type="button" class="mjl-btn mjl-btn--ghost">Ghost</button>

<!-- Tombol Hapus / Batal Penting (Danger) -->
<button type="button" class="mjl-btn mjl-btn--danger">Hapus Berkas</button>
```
::

| Variasi | Kelas CSS | Rekomendasi Penggunaan |
| :--- | :--- | :--- |
| **Primary** | `.mjl-btn--primary` | Hanya **satu per tampilan utama**: Kirim formulir, Lanjut tahap berikutnya. |
| **Secondary** | `.mjl-btn--secondary` | Aksi pendukung: Simpan draf, Cetak pratinjau, Filter tabel. |
| **Outline** | `.mjl-btn--outline` | Aksi alternatif dengan penekanan visual sedang: Kembali, Batal. |
| **Ghost** | `.mjl-btn--ghost` | Aksi rendah penekanan di dalam tabel atau header kartu: Sunting, Salin. |
| **Danger** | `.mjl-btn--danger` | Tindakan destruktif tidak dapat diulang: Hapus akun, Batalkan izin. |

## 2. Ukuran Tombol & Standar Sentuh

<div class="flex flex-wrap items-center gap-4">

  <button type="button" class="mjl-btn mjl-btn--primary mjl-btn--lg">Besar (lg - 52px)</button>

#code
```html
<!-- Ukuran Kecil (Gunakan hemat pada tabel padat data) -->
<button type="button" class="mjl-btn mjl-btn--primary mjl-btn--sm">Kecil (36px)</button>

<!-- Ukuran Standar (Default wajib untuk formulir publik - Min 44px) -->
<button type="button" class="mjl-btn mjl-btn--primary">Standar (44px)</button>

<!-- Ukuran Besar (Call-to-Action pada landing page) -->
<button type="button" class="mjl-btn mjl-btn--primary mjl-btn--lg">Besar (52px)</button>
```
::

> [!IMPORTANT]
> Jangan gunakan ukuran `.mjl-btn--sm` untuk alur utama pada perangkat seluler. Standar aksesibilitas kependudukan mewajibkan target sentuh fisik minimum 44px agar mudah ditekan oleh jempol warga lansia.

## 5. Integrasi Vue 3 (`@majalengka/vue`)

Jika menggunakan tumpukan Vue 3 atau Nuxt, impor komponen `<MjlButton>`:

```vue
<script setup lang="ts">
import { MjlButton } from '@majalengka/vue';
import { ref } from 'vue';

const isSubmitting = ref(false);

async function handleSubmit() {
  isSubmitting.value = true;
  await submitRegistration();
  isSubmitting.value = false;
}
</script>

<template>
  <div class="flex gap-3">
    <MjlButton
      variant="primary"
      size="md"
      :loading="isSubmitting"
      @click="handleSubmit"
    >
      Kirim Permohonan
    </MjlButton>

    <MjlButton variant="outline" to="/layanan">
      Batal
    </MjlButton>
  </div>
</template>
```

### Properti Komponen (Props API)

| Properti | Tipe | Nilai Bawaan | Deskripsi |
| :--- | :--- | :--- | :--- |
| `variant` | `'primary' \| 'secondary' \| 'outline' \| 'ghost' \| 'danger'` | `'primary'` | Variasi gaya visual |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Ukuran tombol fisik |
| `loading` | `boolean` | `false` | Menampilkan spinner dan menonaktifkan klik |
| `disabled` | `boolean` | `false` | Menonaktifkan interaksi tombol |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Atribut tipe HTML |
| `to` | `string` | `undefined` | Jika diisi, tombol dirender sebagai tautan semantic (`<a>`) |

## 6. Kaidah Aksesibilitas (WCAG 2.1 AA)

- **Target Sentuh Minimum**: Tombol `md` memiliki tinggi fisik `44px`, mencukupi Success Criterion 2.5.5.
- **Rasio Kontras**: Teks putih pada Biru Majalengka 700 (`#0014A8`) menghasilkan kontras **10.5:1** (jauh melampaui ambang batas 4.5:1).
- **Indikator Fokus**: Menggunakan cincin fokus ganda (`outline: 3px solid var(--mjl-color-primary-300)`) yang terlihat jelas saat navigasi menggunakan tombol `Tab`.
- **Screen Reader**: Jika tombol hanya berisi ikon tanpa teks, **wajib** mencantumkan atribut `aria-label="Nama Aksi"` agar pembaca layar dapat membacakannya.
