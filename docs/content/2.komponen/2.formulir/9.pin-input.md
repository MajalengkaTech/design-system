# PinInput

PinInput memecah kode verifikasi SMS / WhatsApp menjadi 6 kotak masukan terpisah, memudahkan warga memverifikasi angka tanpa salah ketik (**Hukum Miller & Chunking**).

---

---

Coba ketik angka: fokus pindah sendiri ke kotak berikutnya. `Backspace` di kotak kosong mundur ke kotak sebelumnya, panah kiri/kanan berpindah kotak, dan menempel kode utuh (misalnya `482915`) langsung mengisi semua kotak.

---

## Penggunaan

```html
<div class="mjl-pin-input" data-mjl-pin>
  <input type="text" class="mjl-pin-input__box">
  <input type="text" class="mjl-pin-input__box">
  <input type="text" class="mjl-pin-input__box">
  <input type="text" class="mjl-pin-input__box">
  <input type="text" class="mjl-pin-input__box">
  <input type="text" class="mjl-pin-input__box">
</div>
```

Atribut `data-mjl-pin` mengaktifkan perilaku dari `@majalengka/js`. Script itu juga mengisi `inputmode="numeric"` (keyboard angka di ponsel), `autocomplete="one-time-code"` (kode dari SMS bisa diisi otomatis), dan label "Digit 1 dari 6" untuk pembaca layar.

::note
Jangan pasang `maxlength="1"`. Atribut itu mencegah kotak yang sudah terisi ditimpa dengan ketikan baru. Batas satu karakter per kotak sudah diurus script.
::
