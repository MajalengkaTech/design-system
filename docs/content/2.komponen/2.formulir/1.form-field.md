# FormField (Pembungkus Bidang Isian)

Komponen `FormField` (`.mjl-form-field`) adalah fondasi utama seluruh formulir pelayanan publik di Kabupaten Majalengka. Komponen ini memastikan setiap kolom masukan memiliki keterkaitan aksesibel yang benar antara label, petunjuk, dan pesan error sesuai standar **WCAG 2.1 Level AA**.

---

## 2. Struktur Anatomi Komponen

1. **Label (`.mjl-label`)**: Menjelaskan informasi apa yang harus diisi. Wajib memiliki atribut `for="id-input"`.
2. **Tanda Wajib (`.mjl-label__required`)**: Bintang merah `*` dengan atribut `aria-hidden="true"` (pembaca layar cukup membaca teks utama).
3. **Input (`.mjl-input`)**: Kolom masukan tempat pengguna mengetik data.
4. **Hint Text (`.mjl-hint`)**: Teks penjelasan pembantu yang dihubungkan dengan atribut `aria-describedby`.
5. **Error Message (`.mjl-error`)**: Pesan kesalahan yang jelas, solutif, dan menggunakan `role="alert"` sehingga langsung dibacakan screen reader saat validasi gagal.

## 3. Integrasi Vue 3 (`@majalengka/vue`)

Komponen `<MjlFormField>` secara otomatis mengaitkan atribut `id`, `for`, `aria-describedby`, dan `aria-invalid`:

```vue
<script setup lang="ts">
import { MjlFormField, MjlInput } from '@majalengka/vue';
import { ref } from 'vue';

const nik = ref('');
const nikError = ref('');

function validateNik() {
  if (nik.value.length !== 16) {
    nikError.value = 'NIK harus tepat berjumlah 16 digit angka.';
  } else {
    nikError.value = '';
  }
}
</script>

<template>
  <MjlFormField
    label="Nomor Induk Kependudukan (NIK)"
    required
    hint="Contoh: 3210123456780001"
    :error="nikError"
  >
    <MjlInput
      v-model="nik"
      placeholder="Masukkan 16 digit NIK"
      maxlength="16"
      @blur="validateNik"
    />
  </MjlFormField>
</template>
```

## 4. Kaidah Anti-Kaku pada Pesan Error

Hindari bahasa birokratis kaku yang membingungkan warga:

| ❌ Hindari (Birokratis / Kaku) | ✅ Gunakan (Jelas & Solutif) |
| :--- | :--- |
| *"Format isian parameter input tidak valid."* | *"Format email salah. Contoh yang benar: nama@gmail.com"* |
| *"Data wajib diisi sesuai regulasi perundang-undangan."* | *"Mohon masukkan nama lengkap sesuai KTP."* |
| *"Ukuran berkas melebihi kuota ambang batas."* | *"Ukuran foto maksimal 2MB. Silakan kompres foto Anda terlebih dahulu."* |
