# FileUpload (Unggah Berkas Persyaratan)

Komponen FileUpload (`.mjl-file-upload`) menyediakan area sentuh luas bagi pengguna seluler untuk memilih foto berkas dari galeri kamera, serta fitur seret-dan-lepas (*drag & drop*) pada peramban komputer.
