# Slider

Slider memungkinkan pengguna memilih nilai numerik fleksibel (misal: radius pencarian fasilitas kesehatan atau batas jarak zonasi sekolah).

---

## Pratinjau Komponen

<div class="mjl-demo-box">
  <div style="max-width: 420px;">
    <div style="display: flex; justify-content: space-between; font-size: 14px; font-weight: 500; margin-bottom: 4px;">
      <span>Radius Fasilitas Kesehatan Terdekat</span>
      <span class="mjl-tabular-nums">5 km</span>
    </div>
    <input type="range" class="mjl-slider" min="1" max="25" value="5">
  </div>
</div>

---

## Penggunaan CSS Murni

```html
<label for="jarak-zonasi" class="mjl-label">Radius Jangkauan</label>
<input id="jarak-zonasi" type="range" class="mjl-slider" min="1" max="50" value="10">
```
