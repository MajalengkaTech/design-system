# Breadcrumb (Navigasi Jejak Rekam)

Breadcrumb (`.mjl-breadcrumb`) menampilkan struktur navigasi dari tingkat beranda hingga halaman yang sedang aktif.

---

## 1. Pratinjau Breadcrumb

::component-demo{title="Pratinjau Breadcrumb"}
<nav aria-label="Jejak Navigasi">
  <ol class="mjl-breadcrumb">
    <li><a href="#">Beranda</a></li>
    <li><a href="#">Kependudukan</a></li>
    <li><a href="#">Kartu Identitas Anak (KIA)</a></li>
    <li aria-current="page">Pengajuan Baru</li>
  </ol>
</nav>

#code
```html
<nav aria-label="Jejak Navigasi">
  <ol class="mjl-breadcrumb">
    <li><a href="/">Beranda</a></li>
    <li><a href="/layanan">Layanan Publik</a></li>
    <li aria-current="page">KTP Elektronik</li>
  </ol>
</nav>
```
