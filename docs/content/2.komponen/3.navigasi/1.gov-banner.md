# GovBanner (Pita Resmi Pemerintah)

`GovBanner` (`.mjl-gov-banner`) adalah komponen **wajib** yang harus diletakkan di baris paling atas (sebelum navigasi utama) pada setiap situs web OPD, kecamatan, desa, dan layanan publik di lingkungan Pemerintah Kabupaten Majalengka.

Komponen ini memberikan jaminan keamanan kepada warga bahwa situs web yang sedang dibuka adalah sah milik pemerintah, bukan penipuan atau phishing.

## 2. Struktur Informasi Keabsahan

Saat pengguna menekan **"Cara Mengidentifikasi"**, tampilkan dua fakta verifikasi:
1. **Domain Resmi `.go.id`**: Portal resmi pemerintah di Indonesia selalu berakhiran `.go.id` atau `.majalengkakab.go.id`.
2. **Koneksi Aman (HTTPS)**: Terdapat ikon gembok aman pada bilah alamat peramban warga.

---

## 3. Integrasi Vue 3 (`@majalengka/vue`)

```vue
<script setup lang="ts">
import { MjlGovBanner } from '@majalengka/vue';
</script>

<template>
  <MjlGovBanner />
</template>
```

Komponen `<MjlGovBanner>` sudah mencakup logika pembukaan panel verifikasi (*collapsible drawer*), bendera SVG merah-putih, dan atribut ARIA lengkap.
