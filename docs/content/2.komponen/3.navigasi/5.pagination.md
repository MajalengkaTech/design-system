# Pagination (Paginasi Halaman Data)

Pagination (`.mjl-pagination`) membagi daftar rekaman data yang panjang menjadi beberapa halaman terpisah sehingga meringankan waktu muat (*load time*) pada koneksi internet lambat di pelosok.

---

## 1. Pratinjau Pagination

::component-demo{title="Pratinjau Paginasi Tabel"}
<nav aria-label="Navigasi Halaman Data">
  <ul class="mjl-pagination">
    <li class="mjl-pagination__item">
      <button type="button" class="mjl-pagination__link" aria-label="Halaman Sebelumnya">
        ← Sebelumnya
      </button>
    </li>
    <li class="mjl-pagination__item">
      <button type="button" class="mjl-pagination__link mjl-pagination__link--active" aria-current="page">1</button>
    </li>
    <li class="mjl-pagination__item">
      <button type="button" class="mjl-pagination__link">2</button>
    </li>
    <li class="mjl-pagination__item">
      <button type="button" class="mjl-pagination__link">3</button>
    </li>
    <li class="mjl-pagination__item">
      <button type="button" class="mjl-pagination__link" aria-label="Halaman Selanjutnya">
        Selanjutnya →
      </button>
    </li>
  </ul>
</nav>
