---
title: SkipLink (Lompat ke Konten Utama)
description: Tautan tersembunyi yang langsung muncul saat tombol Tab ditekan pertama kali untuk memudahkan pengguna disabilitas dan keyboard.
---

`SkipLink` (`.mjl-skip-link`) adalah komponen aksesibilitas mendasar yang diwajibkan oleh **WCAG 2.1 Success Criterion 2.4.1 (Bypass Blocks)**.

Komponen ini tersembunyi di luar layar (*offscreen*) secara default, dan baru melompat muncul ke depan pandangan ketika warga menavigasi situs menggunakan tombol `Tab` pada keyboard.

---

## 1. Pratinjau Interaktif

Klik tombol di bawah untuk melihat wujud SkipLink saat menerima fokus keyboard:

::component-demo{title="Simulasi Fokus SkipLink"}
<div class="p-4 bg-slate-100 rounded-lg text-center">
  <p class="text-xs text-slate-500 mb-3">Tekan tombol Tab pada keyboard Anda atau klik contoh di bawah:</p>
  <a
    href="#konten-utama"
    class="mjl-btn mjl-btn--primary font-bold shadow-lg"
  >
    Lompat langsung ke konten utama →
  </a>
</div>

#code
```html
<!-- Diletakkan tepat setelah tag pembuka <body> -->
<a href="#main-content" class="mjl-skip-link">
  Lompat langsung ke konten utama
</a>

<!-- Kontainer konten utama dengan ID target dan tabIndex -->
<main id="main-content" tabindex="-1">
  <!-- Isi halaman di sini -->
</main>
```
::

---

## 2. Aturan Implementasi Wajib

1. **Target ID yang Valid**: Atribut `href` wajib merujuk ke elemen `<main id="main-content">` halaman Anda.
2. **Atribut `tabindex="-1"`**: Pasang pada elemen `<main>` target agar peramban seperti Safari dan Chrome memindahkan fokus fokus keyboard secara benar tanpa menimbulkan efek visual kotak garis ganda.

## Penggunaan di Berbagai Teknologi

Salin contoh sesuai teknologi proyek Anda. Semua versi memakai class dari `@majalengka/css`. Komponen siap pakai tersedia di `@majalengka/vue`; untuk React, Angular, Laravel, dan PHP, contoh di bawah sudah berupa pembungkus kecil yang bisa langsung disalin ke proyek.

::code-group

```html [HTML]
<body>
  <a href="#konten" class="mjl-skip-link">Langsung ke konten utama</a>
  <header>...</header>
  <main id="konten" tabindex="-1">...</main>
</body>
```

```vue [Vue]
<script setup lang="ts">
import { MjlSkipLink } from '@majalengka/vue';
</script>

<template>
  <MjlSkipLink target-id="#konten" />
  <header>...</header>
  <main id="konten" tabindex="-1"><slot /></main>
</template>
```

```tsx [React]
import type { ReactNode } from 'react';

export function Layout({ children }: { children: ReactNode }) {
  return (
    <>
      <a href="#konten" className="mjl-skip-link">Langsung ke konten utama</a>
      <header>...</header>
      <main id="konten" tabIndex={-1}>{children}</main>
    </>
  );
}
```

```ts [Angular]
import { Component } from '@angular/core';
import { RouterOutlet } from '@angular/router';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [RouterOutlet],
  template: `
    <a href="#konten" class="mjl-skip-link">Langsung ke konten utama</a>
    <header>...</header>
    <main id="konten" tabindex="-1"><router-outlet /></main>
  `,
})
export class App {}
```

```blade [Laravel]
{{-- resources/views/layouts/app.blade.php --}}
<body>
  <a href="#konten" class="mjl-skip-link">Langsung ke konten utama</a>
  @include('partials.header')
  <main id="konten" tabindex="-1">@yield('content')</main>
</body>
```

```php [PHP]
<body>
  <a href="#konten" class="mjl-skip-link">Langsung ke konten utama</a>
  <?php include __DIR__ . '/partials/header.php'; ?>
  <main id="konten" tabindex="-1">
    <?php include $halaman; ?>
  </main>
</body>
```
