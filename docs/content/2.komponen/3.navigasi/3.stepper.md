---
title: Stepper (Indikator Tahapan Formulir)
description: Penanda langkah berurutan untuk memandu warga menyelesaikan formulir permohonan layanan yang panjang.
---

Stepper (`.mjl-stepper`) memecah formulir permohonan perizinan atau kependudukan yang rumit menjadi beberapa tahap logis yang mudah dipahami warga.

Di layar lebar stepper tampil horizontal; di bawah 768px otomatis berubah vertikal agar judul tahap tidak terpotong di HP.

## 3. Status Tahap

| Class | Tampilan | Kapan dipakai |
|-------|----------|---------------|
| `mjl-stepper__item--completed` | Lingkaran biru penuh berisi centang, garis penghubung biru | Tahap yang sudah selesai |
| `mjl-stepper__item--current` | Lingkaran bergaris biru dengan cincin fokus | Tahap yang sedang diisi warga (tambahkan `aria-current="step"`) |
| *(tanpa modifier)* | Lingkaran abu-abu | Tahap yang belum dimulai |

```tsx [React]
const STATUS = { completed: 'Selesai: ', current: 'Tahap saat ini: ', upcoming: 'Belum dimulai: ' } as const;

export function MjlStepper({ steps, current }: { steps: { title: string; desc?: string }[]; current: number }) {
  return (
    <ol className="mjl-stepper" aria-label="Tahapan pengajuan">
      {steps.map((s, i) => {
        const st = i < current ? 'completed' : i === current ? 'current' : 'upcoming';
        return (
          <li key={s.title} className={`mjl-stepper__item ${st !== 'upcoming' ? `mjl-stepper__item--${st}` : ''}`} aria-current={st === 'current' ? 'step' : undefined}>
            <span className="mjl-stepper__indicator" aria-hidden="true">{st === 'completed' ? '✓' : i + 1}</span>
            <div className="mjl-stepper__content">
              <span className="mjl-stepper__title"><span className="sr-only">{STATUS[st]}</span>{s.title}</span>
              {s.desc && <span className="mjl-stepper__desc">{s.desc}</span>}
            </div>
          </li>
        );
      })}
    </ol>
  );
}
```

```ts [Angular]
import { Component, input } from '@angular/core';

@Component({
  selector: 'mjl-stepper',
  standalone: true,
  template: `
    <ol class="mjl-stepper" aria-label="Tahapan pengajuan">
      @for (s of steps(); track s.title; let i = $index) {
        <li class="mjl-stepper__item" [class.mjl-stepper__item--completed]="i < current()"
          [class.mjl-stepper__item--current]="i === current()" [attr.aria-current]="i === current() ? 'step' : null">
          <span class="mjl-stepper__indicator" aria-hidden="true">{{ i < current() ? '✓' : i + 1 }}</span>
          <div class="mjl-stepper__content">
            <span class="mjl-stepper__title">
              <span class="sr-only">{{ i < current() ? 'Selesai: ' : i === current() ? 'Tahap saat ini: ' : 'Belum dimulai: ' }}</span>{{ s.title }}
            </span>
          </div>
        </li>
      }
    </ol>
  `,
})
export class MjlStepper {
  steps = input.required<{ title: string }[]>();
  current = input(0);
}
```

## 4. Kaidah Aksesibilitas

1. **Pakai `<ol>`**: urutan tahap ikut terbaca oleh pembaca layar ("daftar, 4 item").
2. **`aria-current="step"`** pada tahap yang sedang berjalan.
3. **Status tidak boleh hanya lewat warna** (WCAG 1.4.1): sertakan teks tersembunyi seperti `<span class="sr-only">Selesai: </span>` di judul tahap. Komponen Vue `MjlStepper` sudah melakukannya otomatis.
4. **Indikator bersifat dekoratif** (`aria-hidden="true"`), karena nomor tahap sudah tersirat dari urutan daftar.
