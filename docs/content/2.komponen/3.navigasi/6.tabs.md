# Tabs

Tabs mengorganisasi konten yang berada pada level hierarki yang sama ke dalam panel terpisah yang dapat dialihkan secara cepat.

---

## Penggunaan CSS Murni

```html
<!-- Tab Garis Bawah -->
<div class="mjl-tabs">
  <ul class="mjl-tab-list" role="tablist">
    <li role="presentation">
      <button class="mjl-tab mjl-tab--active" role="tab" aria-selected="true">Tab 1</button>
    </li>
    <li role="presentation">
      <button class="mjl-tab" role="tab" aria-selected="false">Tab 2</button>
    </li>
  </ul>
</div>

<!-- Tab Pil Kapsul -->
<div class="mjl-tabs mjl-tabs--pill">
  <ul class="mjl-tab-list">
    <li><button class="mjl-tab mjl-tab--active">Tab 1</button></li>
    <li><button class="mjl-tab">Tab 2</button></li>
  </ul>
</div>
```

## Penggunaan Vue 3 (`@majalengka/vue`)

```vue
<!-- import { MjlTabs } from '@majalengka/vue' -->
<script setup lang="ts">
import { ref } from 'vue';
const aktif = ref('syarat');
const tabs = [
  { value: 'syarat', label: 'Persyaratan Permohonan' },
  { value: 'prosedur', label: 'Prosedur Layanan' },
  { value: 'biaya', label: 'Biaya & Waktu Proses' },
];
</script>

<template>
  <MjlTabs v-model="aktif" :items="tabs" label="Informasi layanan">
    <template #syarat>Fotokopi KTP, KK, dan surat pengantar RT/RW.</template>
    <template #prosedur>Ajukan berkas di loket atau secara daring.</template>
    <template #biaya>Gratis, selesai 3 hari kerja.</template>
  </MjlTabs>
</template>
```

Mengikuti pola WAI-ARIA Tabs: `role="tablist"`/`tab`/`tabpanel`, panah kiri/kanan dan Home/End untuk berpindah tab, dan hanya tab aktif yang masuk urutan Tab. Pakai `variant="pill"` untuk gaya pil.
