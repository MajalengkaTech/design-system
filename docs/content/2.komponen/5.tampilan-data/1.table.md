# Table (Tabel Data Responsif)

Tabel (`.mjl-table`) dirancang khusus agar tetap nyaman dibaca di layar smartphone kecil melalui kontainer penggulung (`.mjl-table-container`) dengan indikator bayangan lembut.

## 2. Aturan Aksesibilitas WCAG Tabel

1. **Atribut `scope="col"`**: Wajib disertakan pada setiap tag `<th>` di baris kepala tabel agar pembaca layar mengasosiasikan isi sel dengan nama kolomnya.
2. **Tabindex Kontainer**: Wadah `.mjl-table-container` memiliki atribut `tabindex="0"` dan `role="region"` agar pengguna tunanetra dan pengguna keyboard dapat menggulir tabel horizontal menggunakan tombol panah keyboard.
