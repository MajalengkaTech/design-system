# Accordion (Daftar Lipat / FAQ)

Accordion (`.mjl-accordion`) memungkinkan warga melihat ringkasan topik pertanyaan umum dan membuka detailnya tanpa membuat halaman menjadi terlalu panjang.

Menggunakan elemen semantik bawaan `<details>` dan `<summary>` sehingga bekerja secara native tanpa JavaScript sekalipun.

---

## 1. Pratinjau Accordion Tanya Jawab (FAQ)

::component-demo{title="Pratinjau Tanya Jawab Layanan Kependudukan"}
<div class="mjl-accordion max-w-2xl">
  <details class="mjl-accordion__item" open>
    <summary class="mjl-accordion__summary">
      Berapa biaya pengurusan KTP dan Kartu Keluarga di Majalengka?
      <span class="text-xs text-slate-400">▼</span>
    </summary>
    <div class="mjl-accordion__content">
      <p class="py-2">
        Seluruh pengurusan dokumen kependudukan (KTP, KK, Akta Kelahiran, KIA) di Kabupaten Majalengka adalah <strong>100% GRATIS</strong> (tidak dipungut biaya apapun). Jika ada pungli, laporkan ke Satgas Saber Pungli.
      </p>
    </div>
  </details>

  <details class="mjl-accordion__item">
    <summary class="mjl-accordion__summary">
      Berapa lama waktu penerbitan dokumen setelah berkas diverifikasi?
      <span class="text-xs text-slate-400">▼</span>
    </summary>
    <div class="mjl-accordion__content">
      <p class="py-2">
        Proses verifikasi berkas memakan waktu maksimal 1×24 jam kerja. Dokumen digital (PDF bertanda tangan elektronik BSrE) dapat langsung diunduh dari akun Anda.
      </p>
    </div>
  </details>

  <details class="mjl-accordion__item">
    <summary class="mjl-accordion__summary">
      Bagaimana jika NIK saya tidak terbaca saat mendaftar?
      <span class="text-xs text-slate-400">▼</span>
    </summary>
    <div class="mjl-accordion__content">
      <p class="py-2">
        Silakan lakukan sinkronisasi data NIK melalui layanan WhatsApp Halo Dukcapil Majalengka atau datangi kantor kecamatan terdekat pada hari kerja.
      </p>
    </div>
  </details>
</div>
