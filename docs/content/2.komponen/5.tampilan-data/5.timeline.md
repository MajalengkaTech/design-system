# Timeline

Timeline memberikan transparansi kepada warga mengenai di dinas atau meja mana berkas permohonan mereka sedang diverifikasi.

```html
  <li class="mjl-timeline__item mjl-timeline__item--active">
    <span class="mjl-timeline__marker"></span>
    <div class="mjl-timeline__title">Berkas Disetujui</div>
    <div class="mjl-timeline__time">17 September 2026</div>
    <div class="mjl-timeline__desc">Menunggu pengambilan fisik.</div>
  </li>
  <li class="mjl-timeline__item">
    <span class="mjl-timeline__marker"></span>
    <div class="mjl-timeline__title">Pengajuan Masuk</div>
    <div class="mjl-timeline__time">16 September 2026</div>
  </li>

```

## Penggunaan Vue 3 (`@majalengka/vue`)

```vue
<!-- import { MjlTimeline } from '@majalengka/vue' -->
<MjlTimeline
  :items="[
    { title: 'Berkas diterima', time: '17 Sep 2026, 09.12', datetime: '2026-09-17T09:12', desc: 'Loket Kecamatan Kadipaten' },
    { title: 'Verifikasi data', time: '18 Sep 2026, 10.40', datetime: '2026-09-18T10:40', active: true },
    { title: 'Dokumen terbit' },
  ]"
/>
```

Tahap dengan `active: true` ditandai `aria-current="step"`.
